RideShare AI Pro - MVP Feature List
Total: 33 Features
Timeline: 8-10 weeks
====================================


RIDER FEATURES (15 Features)
====================================

Phase 1: Onboarding
--------------------

1. Phone-Based Registration
   - Phone + OTP diye password chara account create
   - 6-digit OTP SMS e jabe (Twilio)
   - OTP 5 min valid, max 3 attempts
   - Verify hole JWT token diye auto-login
   - Tech: Twilio, Redis, bcrypt, JWT, PostgreSQL

2. Profile Management
   - Name, photo, DOB fill korbe (mandatory)
   - Email, emergency contact (optional)
   - Photo compress hoye cloud e upload hobe
   - Age 18+ check
   - Tech: Supabase Storage, Sharp, PostgreSQL


Phase 2: Ride Booking
--------------------

3. Google Maps Integration
   - Current location auto-detect (GPS)
   - Map drag kore ba search kore pickup select
   - Same vabe drop select
   - Route draw hobe blue line diye
   - Distance ar estimated time show korbe
   - Tech: Google Maps SDK, Places API, Directions API

4. Fare Calculation
   - Formula: Base + (Distance x Rate) + (Time x Rate) x Surge
   - Bike: Base 40 taka, 15 taka/km, 2 taka/min
   - CNG: Base 60 taka, 25 taka/km, 2 taka/min
   - Car: Base 80 taka, 30 taka/km, 2 taka/min
   - Surge pricing: demand/supply ratio theke calculate
   - Nearest 5 taka te round
   - Tech: Google Directions API, PostgreSQL, Redis

5. Ride Booking
   - Confirm Booking tap korle ride create hobe DB te
   - 4-digit pickup OTP generate hobe
   - Status: searching_driver
   - Driver search start hobe
   - Tech: PostgreSQL, bcrypt, UUID

6. Driver Search Status
   - Searching for driver animation show
   - 60 sec e na paile radius 5km theke 10km e barbe
   - Cancel button available
   - Tech: Lottie animations, WebSocket

7. Driver Found Notification
   - Driver accept korle instant notification
   - Driver er photo, name, rating, vehicle details show
   - Pickup OTP code show
   - ETA show (koto min e ashbe)
   - Tech: Socket.io, Firebase, FCM


Phase 3: Live Tracking
--------------------

8. Real-Time Driver Tracking
   - Map e driver er location every 5 sec update
   - Car icon smoothly move korbe
   - Distance ar ETA continuously update
   - Tech: Firebase Realtime Database, Google Maps SDK

9. ETA Updates
   - Every 30 sec e Google API call kore ETA calculate
   - Traffic consider korbe
   - Arriving in X minutes show
   - Tech: Google Directions API, Redis cache

10. Pickup OTP Verification
    - Rider ke 4-digit code show hobe
    - Driver aisle rider code bolbe
    - Driver app e enter korbe, backend verify korbe
    - Wrong hole 3 bar try, por e support contact
    - Tech: bcrypt, PostgreSQL

11. Ride Progress Tracking
    - Ride cholakolin map e current position show
    - Remaining distance, ETA, estimated fare show
    - GPS points record hobe (dispute er jonno)
    - Tech: Firebase, PostgreSQL, Google Maps


Phase 4: Communication
--------------------

12. In-App Chat
    - Rider ar Driver text message korte parbe
    - Real-time delivery (Socket.io)
    - Read receipts, timestamp
    - App background e gele push notification
    - Chat shudhu active ride er somoy
    - Tech: Socket.io, Node.js, FCM


Phase 5: Payment
--------------------

13. Cash Payment
    - Ride shesh hole final fare show
    - Rider cash dibe, driver Cash Received tap korbe
    - Driver rakhbe 75%, Platform er 25%
    - Weekly settlement
    - Tech: PostgreSQL

14. Card Payment (Stripe)
    - Card add korle Stripe tokenize korbe
    - Ride sheshe one-tap payment
    - Fail hole cash option
    - Tech: Stripe SDK, PCI DSS compliant


Phase 6: Notification
--------------------

15. Push Notifications (FCM)
    - Driver arriving, ride accepted, payment success
    - App closed thakleo notification jabe
    - Sound + vibration
    - Tech: Firebase Cloud Messaging



DRIVER FEATURES (12 Features)
====================================

Phase 1: Driver Onboarding
--------------------

16. Driver Registration
    - Phone diye register + Driver role select
    - Same OTP process
    - After registration: status = pending
    - Tech: Same as Feature 1

17. Document Upload
    - NID card (front + back) photo
    - Driving license photo
    - Vehicle details: type, model, registration, photo
    - Bank account details (encrypted)
    - Submit for verification
    - Tech: S3/Supabase Storage, PostgreSQL

18. Pending Verification
    - Admin verify na kora porjonto ride nite parbe na
    - Pending screen show hobe
    - Approved hole notification asbe, online jete parbe
    - Rejected hole reason dekhabe, re-upload korte parbe
    - Tech: FCM, Conditional UI


Phase 2: Driver Operations
--------------------

19. Go Online/Offline Toggle
    - Toggle on korle ride request pabe
    - GPS tracking start hobe every 5 sec
    - Redis GEOADD e add hobe (nearby search er jonno)
    - Toggle off korle stop, ride request band
    - Active ride thakle offline jete parbe na
    - Tech: Redis GEOADD, Firebase, GPS

20. Ride Request Notification
    - Nearby ride booking hole push notification
    - Pickup, drop, fare, distance show
    - 30 second timer countdown
    - Time shesh hole auto-decline, next driver ke jabe
    - Loud sound + vibration
    - Tech: FCM, Socket.io

21. Accept/Decline Ride
    - Accept tap korle database transaction lock korbe
    - First lock wins (race condition handle)
    - 2 jon same time e accept korleo 1 jon pabe
    - Decline korle acceptance rate kombo
    - 70% er niche acceptance rate hole warning
    - Tech: PostgreSQL SELECT FOR UPDATE, WebSocket


Phase 3: Ride Execution
--------------------

22. Navigate to Pickup
    - Google Maps navigation follow kore rider er kache jawa
    - Turn-by-turn voice direction
    - Real-time traffic avoidance
    - 100m er moddhe aisle I have Arrived button
    - Tech: Google Maps SDK, Directions API, TTS

23. Pickup OTP Verification (Driver Side)
    - Rider ke code jiggesh korbe
    - App e 4-digit code enter korbe
    - Verify hole Start Ride button unlock
    - Wrong hole 3 attempts, por e support
    - Tech: Same as Feature 10

24. Start Ride
    - OTP verify por Start Ride tap
    - Status: started, timestamp record
    - GPS route recording shuru (every 5 sec)
    - Rider ke notification: Your ride has started
    - Cancel free na, fee lagbe
    - Tech: PostgreSQL, GPS, WebSocket

25. Navigation During Ride
    - Google Maps follow kore destination e jawa
    - GPS points store hobe ride_route_points table e
    - Rider live tracking dekhbe
    - Dispute resolution er jonno GPS proof
    - Tech: Google Maps, PostgreSQL, Firebase

26. End Ride
    - Destination e End Ride tap
    - Actual distance calculate (GPS points theke Haversine)
    - Actual time calculate (started_at theke completed_at)
    - Final fare compute kore both ke show
    - Tech: Haversine formula, PostgreSQL


Phase 4: Payment
--------------------

27. Collect Payment
    - Cash/card receive kore Payment Received confirm
    - Earnings split: Driver 75%, Platform 25%
    - Tech: PostgreSQL



ADMIN FEATURES (4 Features)
====================================

28. Driver Document Verification
    - Pending drivers list dekha (admin web panel)
    - NID, license, vehicle photo zoom kore check
    - Checklist: clear? valid? matches? condition?
    - Approve korle driver active hobe
    - Reject korle reason diye notification jabe
    - Driver re-upload korte parbe
    - Tech: React.js, Lightbox, FCM + Email + SMS

29. Admin Dashboard
    - Total rides, revenue, users, online drivers
    - Charts: rides over 7 days, revenue breakdown
    - Live map: active rides, available drivers
    - Pending actions: verifications, disputes
    - Recent activity feed
    - Tech: React.js, Chart.js, Google Maps, Socket.io

30. Ride Monitoring
    - All rides filter: status, date, driver, rider, payment
    - Ride details: route map, fare breakdown, timeline
    - Active rides live tracking
    - Emergency cancel option (with reason + refund)
    - Bulk export: CSV, Excel
    - Tech: React, SQL JOINs, WebSocket, Google Maps

31. User Management
    - Search users by name/phone/ID
    - Filter by role/status
    - View: profile, ride history, payment history, ratings
    - Actions: block/unblock (with reason), admin notes
    - Tech: PostgreSQL CRUD



PAYMENT GATEWAY (1 Feature)
====================================

32. bKash Payment Integration
    - bKash tokenized checkout API
    - First time: bKash authorize korbe, agreement token save
    - Next time: one-tap payment via saved token
    - Fee: 1.85% per transaction
    - Tech: bKash API, PostgreSQL
