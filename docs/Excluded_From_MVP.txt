1. Core Ride Flow age dorkar
   Registration, Booking, Matching, Tracking, Payment, Rating
   Eta chara app cholbe na - tai etai MVP

2. Chat ache tai Voice Call chara cholbe
   WebRTC complex, MVP te chat diye communicate hobe

3. Parcel delivery alada module
   Ride-sharing stable hole add korbe

4. Advanced admin tools pore
   Shurute 1-2 admin manually manage korbe

5. Heatmap o Performance Metrics
   Data chara meaningless, launch er por data hole korbe

6. Web Portal
   Mobile-first, web pore korbe

7. Fleet Management
   Individual drivers age, fleet pore

Phase 3 needs Phase 2 ready:
