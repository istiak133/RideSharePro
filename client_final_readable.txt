RideShare AI Pro
Complete Feature List — Merged (MVP + Client Requirements)
Total Features: 51  |  Platform: iOS & Android + Admin Web Panel


Category 1: Rider (Customer) Features — 18 Features

Phase 1: Onboarding

Feature 1: Phone-Based Registration
User phone number diye register kore, kono password lagena. Phone dile system SMS-e 6-digit OTP pathay. OTP correct hole account toiri hoy ebong automatically login hoy. Security er jonno OTP matro 5 minute valid thake, ghontay shorboccho 5 bar OTP request kora jay, ebong 3 bar bhul dile temporary block hoy. Rate limiting (5 requests/hour per phone, 50 requests/hour per IP) apply hoy spam prevent korte.
Feature 2: User Profile Management
Registration er por user tar naam, chhobi, jonmo-tarikh diye profile shompurno kore — eta mandatory. Optional field e email ebong emergency contact (naam + phone) thake. Driver-der jonno additional mandatory fields: NID card (front + back), driving license, vehicle type (shudhu Car — no bike/CNG), vehicle model, registration number, vehicle photo, ebong bank account details. Shob chhobi client-side e compress hoy upload er age. Driver submit korle status hoy 'Pending Verification'.

Phase 2: Ride Booking

Feature 3: Google Maps Integration
Rider app open korle device er GPS diye current location automatically detect hoy. Rider pickup point ebong destination manually search korte pare othoba map-e tap kore select korte pare. Route, estimated distance ebong estimated time dekhay. Google Places Autocomplete diye address search easy hoy.
Feature 4: Vehicle Type Selection (Cars Only)  [CLIENT REQUIREMENT]
Is release e rider shudhu Car select korte parbe — bike, CNG, van kono option thakbe na. Car select korle tar fare structure, availability, ebong driver pool accordingly filter hoy. Future phases e onno vehicle type add kora jabe.
Feature 5: Dynamic Fare Calculation
System automatically fare calculate kore: Base fare + (distance x per-km rate) + (time x per-minute rate). Demand beshi thakle surge multiplier apply hoy (max 3x cap). Surge calculate hoy nearby active rides vs available drivers er ratio diye. Rush hour ba bristir shomoy surge bare. Final fare rider ke breakdown shohit dekhano hoy — transparency er jonno. Fare estimate confirm er age rider clearly dekhte pay keno eta taka.
Feature 6: Ride Booking
Rider fare dekhe confirm korle database-e ride record toiri hoy 'searching_driver' status diye. System immediately nearby driver khuja shuru kore. Rider ke confirmation screen dekhay ride ID shohit.
Feature 7: Schedule-a-Ride  [CLIENT REQUIREMENT]
Rider ekhoni noy, 1 ghonta theke 7 din age porzonto advance booking korte parbe. Booking er shomoy pickup time, date, ebong timezone specify kore. System scheduled time er 15 minute age nearby drivers ke notification pathay. Kono driver accept na korle 10 minute age auto-retry hoy wider radius e. Timezone differences handle kora hoy server-side UTC conversion diye — rider local time dekhbe, system UTC e store kore. Rider scheduled ride cancel korte parbe free of cost jodi 30 minute er beshi shomoy baki thake.
Feature 8: Driver Search Status
Booking confirm howar por rider ke 'Searching for driver...' screen dekhano hoy real-time animation shohit. System 5km radius er moddhe online drivers khoje. Na pele radius 10km kora hoy. Jotokhon driver na pawa jay rider ei screen e thake. Notificaiton ashe jei matro driver pawa jay.

Phase 3: Live Tracking & Ride Execution

Feature 9: Real-Time Driver Location Tracking
Driver ride accept korar por rider ekta map dekhe jekhane driver er location live update hote thake. Driver app proti 5 second e tar GPS location Firebase Realtime Database-e push kore, rider er app ta instantly receive kore map-e update kore smooth animation shohit. ETA automatically recalculate hoy traffic consider kore.
Feature 10: Pickup OTP Verification
Booking er shomoy rider ke ekta 4-digit code deowa hoy — bড় bold font e display hoy, copy button ache. Driver pickup location-e pouchhiye rider ke ei code jigges kore. Code correct hole ride shuru kora jay. Wrong person er fraud prevent kore — code na janle keu 'Aami Ahmed' bole উঠতে পারবে না. Max 3 attempts, bcrypt hashing, audit log — shob security measure ache.
Feature 11: Ride Progress Tracking
Ride chalukale rider ekta live map dekhe — garir current location, destination, remaining distance, ETA shob real-time update hoy. Driver er GPS data Firebase-e jay ebong rider er app ta live reflect kore. Rider destination e pouchhanor estimated time countdown hisebe dekhe.

Phase 4: Communication

Feature 12: In-App Chat  [CLIENT REQUIREMENT]
Rider ebong Driver ekke opporoke text message korte parbe ride er moddhe — phone number share na kore. 'Ami niche ashchi', 'Apni kothay?' erokom simple communication er jonno. Messages real-time e jay Firebase ba dedicated chat service (e.g. Stream Chat) diye. Ride shesh hole chat history 24 ghonta accessible thake. Phone number privacy maintain hoy shobshomoy.

Phase 5: Payment

Feature 13: Cash Payment
Ride sheshe rider driver ke cash dey. Driver app-e 'Cash Received' confirm korle system payment complete hisebe record kore. Platform commission (25%) automatically alada kora hoy, driver er earning (75%) calculate hoy. Weekly settlement system e driver platform er commission ongsho bKash/bank transfer diye dey.
Feature 14: Card Payment (Stripe)  [CLIENT REQUIREMENT]
Rider tar debit/credit card ekbar add korle poror bar shudhu confirm korle payment hoy. Stripe card number kokhono directly store kore na — secure token rakhe (PCI DSS compliant). Ride sheshe automatically charge hoy. Sandbox tested, production keys swap korle live hobe. Failed payment hole fallback option (cash) dekhay.
Feature 15: Bilingual UI — English + 2nd Language  [CLIENT REQUIREMENT]
Entire app er UI English ebong client-supplied 2nd language e switch korte parbe seamlessly. Language files alag alag folder e rakha thakbe (e.g., /locales/en.json, /locales/bn.json) — easy editing er jonno. User profile e preferred language save hoy. App restart na kore instant language switch hoy. Date, time, currency format o language onujayi change hoy.

Phase 6: Post-Ride

Feature 16: Rating & Review System
Ride sheshe rider driver ke 1-5 star dey ebong comment likhte pare. Driver o rider ke rate kore. Rating profile e average hisebe dekhe. Low rating driver der priority kome jay matching algorithm e. Consistently kharap rider der warning dewa hoy. Rating deowa mandatory — skip korle next booking block hoy na but reminder ase.
Feature 17: Push Notifications
Shob important events e user ke phone notification jay via Firebase Cloud Messaging (FCM): driver accepted, driver arriving, driver arrived, ride started, ride completed, payment confirmed, scheduled ride reminder (15 min age). Phone bondho screen e thakleo notification ase ebong tap korle directly relevant screen e niye jay.
Feature 18: Ride History
Rider tar shob past rides er list dekhte parbe — date, route, fare, driver, rating shohit. Specific ride tap korle full details dekhe — map route, fare breakdown, receipt. PDF receipt download ba email kora jay. Upcoming scheduled rides alag section e highlighted thake.



Category 2: Driver Features — 14 Features

Phase 1: Onboarding

Feature 19: Driver Registration
Rider registration er motoi phone + OTP diye, tobe role hisebe 'Driver' select korte hoy. Same security measures apply: OTP expiry, rate limiting, attempt limits.
Feature 20: Document Upload & Verification
Driver NID (front+back), driving license, vehicle photo (Car only), vehicle details ebong bank account upload kore. Shob document admin panel e joma hoy manual review er jonno. Status hoy 'Pending Verification'. Driver kono ride nite parbe na jotokhon approved na hoy.
Feature 21: Pending Verification Status
Document submit korar por driver app-e clear status dekhay 'Under Review'. Admin approve korle FCM notification ase 'Congratulations! You are verified.' Reject hole reason shohit notification ase ebong specific documents resubmit option thake.

Phase 2: Driver Operations

Feature 22: Go Online/Offline Toggle
Driver kaj korte chaile 'Online' toggle kore. Takhon location tracking shuru hoy, driver nearby search e dekha jay, ride requests ase. Kaj shesh hole 'Offline' korle shob bondho hoy. Active ride thakle offline kora jay na. 'Break' mode o ache — location track hoy kintu new request ase na.
Feature 23: Ride Request Notification
Driver online thakle kacher ride request ashle urgent notification ase — pickup address, destination, fare, distance shohit. 30 second er moddhe respond na korle auto-decline hoy ebong next driver ke pathano hoy. Custom alert sound thake.
Feature 24: Accept / Decline Ride
Driver Accept ba Decline korte pare. Accept korle database-e race condition prevent korte row-level lock use hoy — duijone ekshonge accept korleo ekjon i pabe. Decline korle acceptance rate kome (70% er niche hole priority kome, bonus eligibility hara jay). Accept decline er karon track hoy analytics er jonno.
Feature 25: Navigate to Pickup
Driver accept korar por Google Maps integration diye pickup location e navigate korte pare. In-app navigation othoba external Google Maps app — duita option ache (user preference). Turn-by-turn voice directions, real-time traffic, alternative routes shob thake. Rider simultaneously driver er location dekhte thake.

Phase 3: Ride Execution

Feature 26: Pickup OTP Verification (Driver Side)
Driver pickup location e pouchhe 'I've Arrived' tap kore. Screen e rider ke code jigges korar prompt ase. Driver 4-digit code enter kore verify kore. Correct hole 'Start Ride' button active hoy. 3 bar wrong dile auto-investigation trigger hoy.
Feature 27: Start Ride
OTP verified hole 'Start Ride' button active hoy. Tap korle ride officially shuru hoy, GPS recording chalu hoy, timer shuru hoy, destination navigation shuru hoy. Rider ke real-time notification jay 'Your ride has started'.
Feature 28: Navigation During Ride
Ride chalukale destination e jaowar navigation. Proti 5 second e GPS point record hoy database e — eta pore fare verification ebong dispute resolution e kaj ase. Route deviation detect korte pare (wrong route er jonno fare dispute handle korte).
Feature 29: End Ride
Driver destination e pouchhe 'End Ride' tap kore. System takhon actual distance (GPS points theke) ebong actual time hishab kore final fare calculate kore. Booking time er surge use hoy (fair to user). Ride status 'completed' hoy ebong payment flow shuru hoy.
Feature 30: Collect Payment & Basic Earnings View
Payment confirm korar por driver er earnings real-time update hoy. Driver app e today's trips, total earnings, weekly earning dekha jay. Cash collection tracking, platform commission breakdown, ebong settlement due amount dekha jay. Detailed analytics Phase 2 e aasbe.

Phase 4: Scheduled Ride Handling (Driver Side)

Feature 31: Scheduled Ride Notification & Accept  [CLIENT REQUIREMENT]
Scheduled ride er 15 minute age nearby drivers ke special notification jay 'Upcoming Scheduled Ride'. Driver accept korle confirmed hoy ebong calendar reminder set hoy. Scheduled ride accept hole driver er status automatically 'busy' hoy sei time slot e — onno ride request oi slot e ashbe na. Driver cancel korle penalty apply hoy (acceptance rate kome more severely).
Feature 32: In-App Chat — Driver Side  [CLIENT REQUIREMENT]
Rider er shonge chat korar option thake. Simple text messaging, real-time. Phone number kono dik theke expose hoy na.



Category 3: Admin / Dashboard Features — 12 Features

Phase 1: Core Admin Operations

Feature 33: Admin Login & 2FA Authentication
Admin der jonno alag login system — email + password + 2-factor authentication (TOTP/SMS). Regular user login er shonge kono connection nei. Session timeout, brute-force protection, IP-based rate limiting shob ache. Shob admin action audit log e record hoy.
Feature 34: Role-Based Access Control (RBAC)
Admin der duita role: Super Admin (shob kicu korte pare, other admins create/delete korte pare) ebong Verifier (shudhu documents verify korte parbe, financial data dekhte parbe na). Future e Finance role add kora jabe. Protiটা action kono admin korlo, kakhon korlo shob log e thake.
Feature 35: Driver Verification
Pending driver der list dekhha, documents zoom kore check kora, approve ba reject kora. Documents side-by-side comparison. Reject korle karon select korte hoy (predefined reasons + custom note) ebong driver ke notification jay. Driver specific documents resubmit korte pare. Verification checklist (NID, license, vehicle, bank) step-by-step complete korte hoy.
Feature 36: Admin Dashboard
Platform er real-time overview: aajker total rides, revenue, active drivers, waiting riders. Charts e last 7 days er ride trend, revenue breakdown (pie chart). Live map e active rides, available drivers, waiting riders different colors e dekha jay. WebSocket diye 30 second e automatically refresh hoy. Pending actions section e unread verifications, disputes, overdue settlements dekhay. Quick links shob section e.
Feature 37: Ride Monitoring
Shob rides er list — filter kora jay status, date, driver, rider diye. Jokono ride er full details dekhha, live location track kora, emergency cancel kora, ebong refund issue kora. Route taken map e dekhha jay. Timeline of all events (booking → driver assigned → started → completed) visible. Admin notes add kora jay.
Feature 38: User Management
Admin jokono user ke search kore tar shob history dekhte parbe — rides, payments, ratings, complaints. Block ba unblock korte parbe karon ullekh kore. Blocked user ride book/accept korte parbe na. Block er reason log e thake. Admin notes add kora jay user profile e.
Feature 39: Financial Reports
Daily, weekly, monthly revenue report. Platform commission, driver earnings, cash vs card payment breakdown. Excel/CSV/PDF export kora jay. Top earning drivers list. Revenue by date range. Scheduled automated reports email e pathano jay. Refunds issued tracking.
Feature 40: Surge Pricing Control
Admin manually surge on/off korte parbe specific zones ba all zones e. Automatic surge system e demand/supply ratio dekhe system nijei surge set kore. Maximum surge cap (3x) set thake — kono obosthai exceed hobe na. Surge active thakle rider ke clearly dekhano hoy.
Feature 41: Promo Code Management
Admin discount codes toiri korte parbe — percentage ba flat amount, specific vehicle type ba specific users er jonno, expiry date shohit. Promo usage tracking — koto bar use hoyeche, koto revenue affected. Active/inactive toggle. Bulk codes generate kora jay campaign er jonno.
Feature 42: Dispute Resolution
Payment ba ride niye complaints ekta dashboard e ase. GPS trail diye route verification kora jay automatically. Admin dui pokkher katha dekhe shiddhanto ney. Refund issue korte parbe directly admin panel theke. Dispute status (open → investigating → resolved) track hoy. Fraud patterns detect hole auto-flag hoy.
Feature 43: Notification Broadcast
Admin shob users ba specific group ke (shob drivers, shob riders, specific zone) push notification pathate parbe. Promotional messages, system updates, emergency alerts. Schedule kore future time e pathano jay. Sent notifications er delivery status track hoy.
Feature 44: Cash Settlement Management
Cash ride er jonno driver platform er commission (25%) alada kore rakhe. Weekly ba monthly settlement system e driver bKash/bank transfer diye platform ke commission dey. Overdue settlement track hoy — na dile online status block hoy. Trusted drivers (rating 4.7+, no issues) er jonno monthly credit system. Monthly earning statement ebong TDS certificate auto-generate hoy driver dashboard theke.
